## What is it?
Seven-segment LEDs are commonly used to display numbers, but by combining multiple units, it is also possible to display images and arbitrary patterns.  
I built a system that controls a large number of seven-segment LEDs to display image data and custom-designed patterns as a large-scale display.

For more details, see: > https://elchika.com/article/256d17d7-ee96-4fee-8e8a-b19cc3068b17/

## HW
<img width="50%" alt="final" src="https://github.com/user-attachments/assets/9cfaa1b0-216b-45c7-99f9-748ff2d10ad6" />


SPRESENSE was used for control.　　
The seven-segment LEDs were controlled using a shift register with a dynamic (multiplexed) driving method.

The PCB design data is available here: > https://github.com/Nanraka/7-segment-LED-display/tree/main/schematics

Please refer to the table below for the connections to the display.  
To distribute the signal lines, I built a custom Arduino shield mounted on the SPRESENSE.

| Spresense Extension Board Pin | Display Pin | Description |
|-----------------------------|------------------------|------|
| D13 (SCK)                   | SCLK                   | SPI clock signal |
| D11 (MOSI)                  | SER, TSER              | Data input (branched to SER and TSER) |
| D9 (CS)                     | CS                     | Chip select (Anode-side shift register) |
| D9                          | RESET                  | Shift register output enable |
| D3                          | TRCLK                  | Chip select (Cathode-side shift register) |
| D1                          | OE                     | Shift register output enable |
| GND                         | GND                    | Ground (common reference) |

⚠️ Please connect a dedicated power supply to the VCC terminal of the seven-segment display.  
⚠️ Do not connect it to the SPRESENSE Vout 5V pin.

## SW

<img width="50%" alt="sw" src="https://github.com/user-attachments/assets/403d357a-2840-4602-af79-5af7dd031d2a" />


The data sent from SPRESENSE to the display is prepared in advance on a PC.  
Python is used to convert the image data to be displayed into binary data.

The software data is available here: > https://github.com/Nanraka/7-segment-LED-display/tree/main/src

### 1. `make_base_csv.py`
This script generates mask data.

### 2. `img_2_serial.py`
This script performs the following processes:

- Resizes the input image  
- Converts the image to a binary (black-and-white) format, reads it column by column, converts it into serial data, and saves the result as `.txt` and `.csv` files  
- Rearranges the serial data into an order that can be visually recognized as an image by humans, and saves it as a `.csv` file

### 3. `make_data_for_7seg.py`
This script performs the following processes:

- Loads mask data that defines the positions of the seven-segment digits  
- Combines the image serial data with the mask data to generate data for displaying on the seven-segment LEDs

### 4. `7seg_spresense.ino`
- This program sends data to the seven-segment display in LSB-first order.
- The `.txt` file generated by `make_data_for_7seg.py` is stored on a microSD card and read by the SPRESENSE for use.
